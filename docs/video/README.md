# Explainer video

`explainer.mp4` (1280x720, H.264 + AAC, about 2 min 30 s), `poster.png`, `preview.gif` and `script.md` are generated by one command:

```
python3 docs/video/make_video.py
```

Requirements: macOS (`say`, voice Samantha), `ffmpeg`, Playwright with an installed Google Chrome, numpy, Pillow. It takes about 3 minutes.

How it works:

- `narration.json` holds the narration (caption text, and an optional spoken variant for the TTS) per scene. Each sentence is spoken separately, so its exact duration drives the scene timeline and the burned-in captions.
- `scenes.html`, `scenes.css`, `scenes.js` are the animated scenes. They are only a video authoring tool (not shipped to the README). Visuals are keyed to narration sentences (`data-s` = appears when sentence N starts) and rendered frame by frame through `window.setT(t)`, so the output is deterministic.
- The live SVG (`demos/svg/latest.svg`) is rendered by Chrome at exactly 640x492, device scale 1, via `demos/svg/harness.py`, and the GPT-2 GIF is reused from `docs/img/gpt2-generation.gif`.
- Scratch files live in a temp directory that is deleted at the end. `--only-plan` prints the timeline; `--shots scene:sentence:offset,...` writes test PNGs to `_shots/` (delete it afterwards).
