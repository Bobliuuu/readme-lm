# Ask the QA transformer in pure Markdown

Pick a question; follow the links to read the answer the 4-bit transformer would generate, one click per decision: a link spans the whole run of characters the model is confident about (probability = product along the run), and the states where it has real alternatives show them as separate links. The text so far is shown in each state. No Action, no JavaScript.
